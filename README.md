### Featured Projects

| Project | What it does | Key result |
|---|---|---|
| 🚚 [Logistics Delivery Performance & Risk Dashboard](https://github.com/Aditya-Kadam-304/logistics-delivery-dashboard) | End-to-end BI pipeline on 180K+ shipment records — automated data pipeline (Python, GitHub Actions), PostgreSQL, SQL risk scoring, and a 2-page Power BI dashboard | Identified root causes behind a 57.3% late-delivery rate, including an SLA design flaw and a real weather-to-delay correlation using historical weather data |
| 🚗 [LLM Safety Architecture for Autonomous Driving](https://github.com/Aditya-Kadam-304/llm-safety-driving) | 8-layer safety system using Qwen 2.5-7B as a constrained advisor | 97% decision accuracy on multi-hazard scenarios (vs 2% baseline) |

| 🛡️ [Adversarial Robustness on CIFAR-10](https://github.com/Aditya-Kadam-304/Fairness-and-Robustness-in-Deep-Learning) | PGD-based adversarial training with targeted and untargeted attacks on ResNet-18 | 84% accuracy under targeted attacks |
